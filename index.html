NOVAAI Backups is a personal application operated by Jamal Aljaberi. It is being configured to encrypt recovery copies of his document system on his Mac and store them in his Google Drive.

Setup in progress · Backup and restore testing pending

What the application does

The intended backup set includes database exports, archived documents, knowledge notes and the configuration needed for recovery. The backup process runs on the owner's Mac using restic and rclone.

Backups are encrypted on the Mac before upload. Restoring them requires the backup encryption key as well as access to the stored backup files.

Why Google Drive access is requested

The owner signs in through Google and authorizes the drive.file permission. This lets the application create its backup folder and upload, read, update or delete backup files it creates or files explicitly authorized for it.

The connection supports scheduled uploads, integrity checks, restore tests and the owner's chosen retention policy. Google Drive storage usage belongs to the authorized account.

Owned and controlled by you

This application is for the owner's personal use. Access can be revoked in Google Account settings. This website provides application information and does not offer sign-in, file upload or account registration.
